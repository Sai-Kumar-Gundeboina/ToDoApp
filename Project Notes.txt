Creation of React app
======================
1. install node.js (using browser)
2. create react app
    1. """ npx create-react-app frontend """
    2. """ cd frontend """
    3. """ npm run """
Learnings of React:
    - Each component should be used for single purpose
    - useEffect() to synchronize component state with props.

APIs:

| Method | Endpoint      | Purpose            |
| ------ | ------------- | ------------------ |
| POST   | `/tasks`      | Add Task           |
| GET    | `/tasks`      | Get All Tasks      |
| GET    | `/tasks/{id}` | Get One Task       |
| PUT    | `/tasks/{id}` | Update Entire Task |
| DELETE | `/tasks/{id}` | Delete Task        |

Table:
    CREATE TABLE tasks
    (
        id SERIAL PRIMARY KEY,

        task_name VARCHAR(255) NOT NULL,

        description TEXT,

        deadline DATE NOT NULL,

        status BOOLEAN NOT NULL DEFAULT FALSE,

        created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,

        updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
    );

Technologies:
    FastAPI
    SQLAlchemy 2.0 (ORM)
    Pydantic
    PostgreSQL
    Alembic (for database migrations)
    Uvicorn

steps:
    1. install python (using browser)
    2. install virtualenv package:
        - pip install virtualenv
    3. create virtual environment
        - python -m venv venv
    4. activate the virtual environment
        - venv\Scipts\activate
    5. install all other required packages
        - pip install fastapi
        - pip install uvicorn
        - pip install sqlalchemy
        - pip install psycopg2-binary
        - pip install python-dotenv
        - pip install pydantic[email]
    6. Freeze requirements :
        - pip freeze > requirements.txt
