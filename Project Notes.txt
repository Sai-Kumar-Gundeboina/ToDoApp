Creation of React app
======================
1. install node.js (using browser)
2. create react app
    1. npx create-react-app frontend 
    2. cd frontend 
    3. npm start 
    4. npm install (to install dependencies in new PC)
Learnings of React:
    - Each component should be used for single purpose
    - useEffect() to synchronize component state with props.

APIs:

| Method | Endpoint      | Purpose            |
| ------ | ------------- | ------------------ |
| POST   | `/tasks`      | Add Task           |
| GET    | `/tasks`      | Get All Tasks      |
| GET    | `/tasks/{id}` | Get One Task       |
| PUT    | `/tasks/{id}` | Update Entire Task |
| DELETE | `/tasks/{id}` | Delete Task        |

Table:
    CREATE TABLE tasks
    (
        id SERIAL PRIMARY KEY,

        task_name VARCHAR(255) NOT NULL,

        description TEXT,

        deadline DATE NOT NULL,

        status BOOLEAN NOT NULL DEFAULT FALSE,

        created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,

        updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
    );

Technologies:
    FastAPI
    SQLAlchemy 2.0 (ORM)
    Pydantic
    PostgreSQL
    Alembic (for database migrations)
    Uvicorn

steps:
    1. install python (using browser)
    2. install virtualenv package:
        - pip install virtualenv
    3. create virtual environment
        - python -m venv venv
    4. activate the virtual environment
        - venv\Scipts\activate
    5. install all other required packages
        - pip install fastapi
        - pip install uvicorn
        - pip install sqlalchemy
        - pip install psycopg2-binary
        - pip install python-dotenv
        - pip install pydantic[email]
    6. Freeze requirements :
        - pip freeze > requirements.txt
        - pip install -r requirements.txt

Code space linux (PostgreSQL setup):
1. update all packages:
    - sudo apt udpdate
2. Install PostgreSQL
    - sudo apt install -y postgresql postgresql-contrib
3. start PostgreSQL server
    - sudo service postgresql start
4. To know status of PostgreSQL server
    - sudo service postgresql status
5. Switch to PostgreS user
    - sudo -u postgres psql
6. connect to PostgreSQL
    - sudo su - postgres
    - psql
6. Change the password
    - ALTER USER postgres WITH PASSWORD 'your_secure_password';
6. To see table structure
    -  \d tasks

Deployment at aws:
==================
systemcd : service Creation
Details needed:
    => pwd
    => which python
    => which uvicorn
create systemcd file
    => sudo nano /etc/systemd/system/fastapi.service

    """
        [Unit]
        Description=FastAPI Todo Application
        After=network.target

        [Service]
        User=ubuntu
        Group=ubuntu

        WorkingDirectory=/home/ubuntu/apps/ToDoApp/Backend

        Environment="PATH=/home/ubuntu/apps/ToDoApp/Backend/venv/bin"

        ExecStart=/home/ubuntu/apps/ToDoApp/Backend/venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000

        Restart=always
        RestartSec=5

        [Install]
        WantedBy=multi-user.target
    """
    Reload systemd
        => sudo systemctl daemon-reload
    Enable the service
        => sudo systemctl enable fastapi
    Start the service
        => sudo systemctl start fastapi
    Check the status
        => sudo systemctl status fastapi
    
Nginx file setup:
    Step 1: Install Nginx
        sudo apt update
        sudo apt install nginx -y
    Step 2: Start Nginx
        sudo systemctl start nginx
    Step 3: Enable it on boot
        sudo systemctl enable nginx
    Step 4: Check its status
        sudo systemctl status nginx
        press q to close

        sudo nano /etc/nginx/sites-available/todoapp

deploying react on s3:
    - Build the React Application
        - npm run build
        It will create build folder inside frontend folder
    - Create S3 Bucket
    - upload the builde folder to bucket
    - Enable Static Website Hosting (in properties)
    - Bucket Policy (in permissions)
        {
            "Version": "2012-10-17",
            "Statement": [
                {
                "Sid": "PublicRead",
                "Effect": "Allow",
                "Principal": "*",
                "Action": "s3:GetObject",
                "Resource": "arn:aws:s3:::YOUR_BUCKET_NAME/*"
                }
            ]
        }
